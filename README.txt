# NEPAL WORLD 3D — installable phone demo

This is an installable web app (PWA) prototype, not yet an Android APK or iPhone App Store app.

## How to publish it for installation
1. Upload the contents of this folder to a static HTTPS host (for example, a GitHub Pages site or another web host).
2. Open the published HTTPS link in Safari on iPhone.
3. Tap Share → Add to Home Screen → Add.
4. On Android Chrome, open the link → menu (⋮) → Install app / Add to Home screen.

## What is in this first prototype
- Walk around a simple illustrated Nepali village.
- Visit a temple and a pond.
- Touch controls designed for phones.
- Basic offline caching after the first successful load.

## Important
This is a first playable prototype, not a full 3D game and not an App Store / Play Store release. The next development steps are a real 3D engine, character selection, missions, Nepal location maps, and native Android/iOS builds.
